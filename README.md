# SAM999 — Gaming Portfolio

This repository provides a GitHub Pages **redirect** to the existing SAM999 Arena website:

- GitHub Pages entry point: https://aahanaahir22.github.io/SAM999/
- Original live portfolio: https://sam999-arena.aahanaahir10.chatgpt.site/

**Important:** This is not a copy of the site's original source code. The FPS game, animations and portfolio still run on the original ChatGPT-hosted site.

## Enable GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
3. Choose **main** and **/(root)** and click **Save**.
4. Visit https://aahanaahir22.github.io/SAM999/ once GitHub Pages has published.

To host the full portfolio directly on GitHub Pages, export or migrate the original website's source code and assets into this repository.
