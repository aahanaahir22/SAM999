# Independent GitHub Pages deployment

Repository: https://github.com/aahanaahir22/SAM999

Publishing root: main branch, /(root). Public URL: https://aahanaahir22.github.io/SAM999/

All application assets use relative URLs, so this project works under /SAM999/. No custom domain or redirect is configured. Do not change the separate aahanaahir22.github.io repository.

Run locally with `python3 -m http.server 8080`. Run checks with `node tests/combat.test.mjs`, `node tests/world.test.mjs`, and `node tests/content.test.mjs`.

The email composer opens the visitor’s email application; it does not claim server delivery. WebGL2 is needed for the game. The portfolio remains usable without WebGL. See STATUS.md for outstanding visual and hardware testing.
